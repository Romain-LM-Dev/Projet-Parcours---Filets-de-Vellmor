# Script de la vidéo de démonstration

Vidéo de démonstration du projet FILETS : une partie jouée par les vrais modèles, racontée par une voix off. Public : élèves d'une école d'ingénieurs généraliste qui choisissent leur dominante.

Fichier : FILETS-demo.mp4, 1920x1080, 4:49 environ. Voix : fr-FR-VivienneMultilingualNeural (edge-tts), débit -4%.

Partie filmée : runs/demo_ia (trois saisons ; Qwen 2.5 3B et 1,5B, tev1 0,8B, Qwen 2.5 7B pour le narrateur).

Carte de titre : FILETS. Une vallée où chaque personnage est une IA. Carte de fin : Dominante IABD — Intelligence artificielle et big data.

Prononciation (la voix seulement, le sous-titre garde le texte) : « Ces IA » est dit « Ces zia » ; « une IA » est dit « une i-a » ; « RAG » est dit « rag ».

« Vidéo ≈ » : début du passage dans la vidéo, à une seconde près. « Partie » : saison et jour de jeu où il commence.
